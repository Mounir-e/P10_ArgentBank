# Argent Bank Frontend

React application for Argent Bank authentication and user profile management.

## Prerequisites

- Node.js 20 or newer
- The Argent Bank API running on `http://localhost:3001`

## Installation

```bash
npm install
npm run dev
```

The development application is available on `http://localhost:5173`.

## Environment

Copy `.env.example` to `.env` to override the default API URL.

## Available commands

- `npm run dev`: start the Vite development server
- `npm run lint`: check the source code with ESLint
- `npm run build`: create the production bundle
- `npm run preview`: serve the production bundle locally
